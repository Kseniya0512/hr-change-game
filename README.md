# HR Change Game

Интерактивная обучающая игра по управлению изменениями.

## Цель
Научить участников применять корпоративный фреймворк управления изменениями.

## Формат
- Онлайн-воркшоп.
- 20 участников.
- 2–3 команды.
- 30 минут на один кейс.
- Куратор-помощник в каждой команде.

## Кейсы
1. Изменение системы премирования.
2. Отмена ДМС с сохранением возмещения медицинских расходов.

## Результат
Каждая команда разрабатывает первоначальный план внедрения изменения.

## Приложение

Реализованы два кейса и шесть игровых экранов, общий план с серверной синхронизацией, роли участника/капитана/куратора/ведущего, сохранение в SQLite, таймеры, предложения, подсказки, события, редактирование материалов и PDF результатов.

Рабочая ветка — **`feat/change-workshop`**. По согласованию с организатором развитие ведётся только здесь, как самостоятельное приложение.

Неожиданные события связаны с конкретными рисками. Команда может необязательно связать своё действие, коммуникацию или собственный риск с карточками кейса. На экране события видны уже подготовленные связанные ответы; выбор события не зависит от поиска слов в тексте. Старые сохранённые раунды остаются доступны без автоматического изменения их материалов.

## Быстрый запуск

Требуется Node.js 24 или новее.

```bash
npm ci
npm run build
npm start
```

Сервер слушает порт 3000. При первом запуске создаётся `.data/host-key` — локальный ключ для формы «Я ведущий». SQLite и ключ хранятся в `.data/`; каталог исключён из Git. Настройки можно задать через переменные окружения и необязательный `.env` по примеру `.env.example`.

Для разработки: `npm run dev` запускает API на 3000 и Vite на 5173 с проксированием запросов. В облачной среде используйте кеш npm в `/workspace/.cache/npm`, если домашний каталог недоступен для записи: `npm ci --cache /workspace/.cache/npm`.

## Проверки

```bash
npm test
npm run typecheck
npm run build
npm run test:e2e
```

Для проверки PDF нужен `pdftotext`; для браузерных сценариев — Chromium (по умолчанию `/usr/bin/chromium`, другой путь — `CHROMIUM_PATH`). Серверные тесты используют настоящую SQLite и 20 одновременных Socket.IO-подключений. Браузерные тесты запускают отдельный сервер с временными данными и проверяют роли, общий план, таймер, оба кейса и PDF.

Подробности: [руководство ведущего](docs/host-guide.md), [согласованный проект](docs/superpowers/specs/2026-11-12-change-game-design.md), [план реализации](docs/superpowers/plans/2026-11-12-change-game.md).

Для встречи с участниками требуется отдельное размещение сервера с HTTPS и постоянным диском. Файлы на GitHub сами по себе не запускают многопользовательскую игру.

Подготовлены бесплатное демо `render.yaml` и отдельный вариант с постоянным диском `deploy/render-persistent.yaml`. Пошагово: [размещение через Render](docs/render-deployment.md). Демо использует временное хранение; для самого воркшопа нужен постоянный диск. Игра находится в ветке `feat/change-workshop`.

## Бесплатный сайт на GitHub Pages

По выбору организатора добавлена автономная версия: каждый заполняет свой план, ответы сохраняются только в его браузере, регистрации нет. Два кейса сохраняются отдельно. Общая синхронизация, роли ведущего/капитана и сбор ответов других пользователей в этой версии не используются.

Готовые файлы сайта находятся в `docs/index.html` и `docs/pages-assets/`, в ветке `feat/change-workshop`. Для публикации откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку **feat/change-workshop**, папку **/docs** и **Save**. Отдельный сервер и платный тариф не нужны. До завершения публикации GitHub адрес не считается работающим.

После публикации ожидаемый адрес: `https://kseniya0512.github.io/hr-change-game/`.

Для пересборки после изменений:

```bash
npm run build:pages
npm run test:pages
```

В Pages-версии кнопка «Сохранить как PDF» открывает печать браузера; выберите PDF. В документ включены 13 разделов и сохранённые ответы. Исходные документы методологии сохранены. Обычная серверная версия по-прежнему собирается через `npm run build`.

Подробности и ограничения локального хранения: [GitHub Pages](docs/github-pages.md).
