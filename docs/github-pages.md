# Бесплатная автономная игра на GitHub Pages

Организатор выбрал вариант 2: каждый работает со своим планом. Сервер и регистрация для сайта не нужны. Одна и та же ссылка открывает индивидуальную копию приложения; она не объединяет ответы разных людей.

## Однократное включение сайта

Откройте https://github.com/Kseniya0512/hr-change-game/settings/pages.

В разделе **Build and deployment**:

1. Source: **Deploy from a branch**.
2. Branch: **feat/change-workshop**; Folder: **/docs**.
3. Нажмите **Save** и дождитесь сообщения GitHub о публикации.

После успешной публикации GitHub покажет адрес сайта. Ожидаемый адрес — https://kseniya0512.github.io/hr-change-game/. До успешной проверки адреса наличие файлов в репозитории не означает, что сайт опубликован.

Текущее подключение GitHub позволяет менять исходники, но не предоставляет операции управления Pages. Поэтому настройку выполняет владелец репозитория. Дополнительные ветки, сервисы и приложения для этой версии не нужны.

## Работа с планом

Выберите кейс, пройдите шесть экранов и нажимайте «Сохранить блок». Сохранённые ответы восстанавливаются при обновлении страницы. Оба кейса хранятся отдельно. Черновики до нажатия кнопки не гарантируются после закрытия или обновления страницы.

Таймер необязателен: его можно запустить, поставить на паузу или продолжить работу после окончания времени. Событие можно открыть вручную; при запущенном таймере оно появляется за семь минут до окончания. Подсказки основаны на существующих материалах.

Кнопка «Сохранить как PDF» открывает печать. Выберите «Сохранить как PDF»: выводятся 13 разделов с сохранёнными ответами текущего кейса. Для передачи результатов ведущему сохраните PDF и отправьте его обычным способом.

Ответы хранятся только в localStorage данного браузера на этом сайте. Другой компьютер, профиль браузера или очистка данных не сохраняют доступ к этому плану. При недоступном хранилище или ошибке сохранения приложение показывает сообщение и не объявляет ответ сохранённым. Повреждённые данные не сбрасываются автоматически. Изменения из устаревшей вкладки отклоняются с предложением скопировать текст перед обновлением страницы.

## Разработка

`npm run build:pages` собирает автономную версию в существующую папку docs/, обновляя только docs/index.html, docs/.nojekyll и генерируемую папку docs/pages-assets/. Документация не очищается. Относительные пути работают в /hr-change-game/.

`npm run test:pages` проверяет сборку, оба кейса, сохранение, отказ записи, работу без API, мобильную ширину и реальный печатный PDF. Обычная серверная версия остаётся доступна через npm run build и npm start.
